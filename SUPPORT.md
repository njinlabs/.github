# Support

- **Questions and ideas:** use the Discussions tab of the repository, or [njinlabs/njin Discussions](https://github.com/njinlabs/njin/discussions)
- **Documentation:** [njin.run/docs](https://njin.run/docs)
- **Bugs:** open an issue with steps to reproduce
- **Security problems:** use the repository's Security tab (Report a vulnerability), never a public issue
